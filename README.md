# Pebble Energy Tariffs

Displays dynamic energy tariffs on the Pebble watch. Currently, only Dutch tariffs are supported (like Zonneplan and Tibber) and only in hourly rates (I think the quarterly rates are only useful for usage in automations).
The tariffs are obtained from the website public.api.energyzero.nl. You can configure the "inkoopvergoeding" and inclusion of VAT and energy taxes, if you want to include any of them is the displayed tariffs.
